# 0.99 毫秒很漂亮，錄音室還要看完整路徑

Audient 推出 Horizon 8P、16 與 32 三款 Thunderbolt 3 錄音介面，直接把低延遲與大型 I/O 擴充放到台前。

官方已確認的重點有三個：

- 32-bit mastering-grade 轉換
- 192kHz 時官方稱 0.99ms 往返延遲
- 4 台 Horizon 32 可達 200×200 I/O

從技術面看，以主機運算處理原生外掛；ORBIT 可變阻抗調整麥克風前級；macOS 單一驅動整合多台系統。這些規格描述的是設計方向，不等於每個人的實際使用結果。聲音、延遲、手感與工作流程，仍要放進真實創作或演出環境裡判斷。

我的看法是：延遲要看取樣率、buffer 與實際插件鏈。通道多不等於工作流自然清楚。好介面的價值是讓錄音者忘記它的存在。科技成為創作者的另一雙手之前，先要願意接受創作者用耳朵、手感與權利條件來驗收。

我也想多補一句鼓勵：低延遲與彈性擴充，確實能替大型錄音省下很多溝通成本。從小型 session 先測穩定度，再逐步擴張，就能讓規格真正服務表演。
當技術摩擦降低，錄音者就能把更多專注放回呼吸、節奏與彼此的互動。
