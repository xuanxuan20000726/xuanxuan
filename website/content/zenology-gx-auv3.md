# iPad 合成器進入 AUv3，靈感終於不用停在獨立 App

Roland 確認 ZENOLOGY GX for iPad 從 1.9.3 版開始支援 AUv3，終於能直接待在常用的 iPad DAW 裡。

官方已確認的重點有三個：

- 1.9.3 或更新版本支援 AUv3
- 可用於 Logic Pro for iPad、GarageBand、Cubasis 與 AUM
- ZEN-Core 音色可進入行動製作的插件流程

從技術面看，AUv3 讓 MIDI、automation 與專案召回更一致；多實例會增加記憶體與處理器負擔；桌面版、iPad 版與 Roland Cloud 授權仍需分開核對。這些規格描述的是設計方向，不等於每個人的實際使用結果。聲音、延遲、手感與工作流程，仍要放進真實創作或演出環境裡判斷。

我的看法是：行動創作最大的阻力常是 App 之間不能順利接力。進入宿主比增加更多預設更能改善完成率。重要專案仍要測試存檔召回與離線狀態。科技成為創作者的另一雙手之前，先要願意接受創作者用耳朵、手感與權利條件來驗收。

我也想多補一句鼓勵：AUv3 讓靈感少一次搬運，也提高行動創作完成作品的機會。先用一個小專案測召回與效能，穩定後再擴大使用會更安心。
工具之間少一道牆，就多一次把靈感完成的機會，這是很實際的進步。
