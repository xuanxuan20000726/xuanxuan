# 讓不規則的聲音，也能一起合奏

有些樂器的魅力，就在它不太乖。聲音會扭曲、會碎裂，像是一直在音樂裡保留一點意外。

Neutral Labs 的 Scrooge 近期更新到 1.3。官方版本說明列出 Drumkit 模式、透過 MIDI 音符與控制訊息演奏、以 Program Change 切換節奏型，以及同步相關修正等內容。[官方韌體更新紀錄](https://neutral-labs.com/products/scrooge/downloads)

我覺得這類更新值得注意的地方，是它沒有只往「更怪」的方向走，也在改善一件有個性的樂器，如何和其他設備一起工作。

聲音實驗可以很自由，但當它進入一首歌或一場演出，就需要和時間、段落與其他聲部建立關係。能透過 MIDI 演奏或切換設定，意味著創作者有更多機會把變化安排在需要的位置，而不是每次都靠現場手忙腳亂地補上。

同步也不是規格表裡看起來很小的項目。多台設備一起跑的時候，開始、停止、重新進入節拍，都會影響實際操作。新版本的修正值得關注，但仍要在自己的連接方式下驗證，不能把更新紀錄當成所有情境的穩定保證。

如果我把這類聲音放進作品，會先決定哪些地方要保留偶然，哪些地方必須準確。可能讓音色自由變動，但把進場與結尾控制好；也可能先錄下幾段實驗，再挑出能呼應旋律的片段。

這是我依版本資訊提出的製作思路，不是實機評測。韌體升級前，也會先確認自己的硬體版本、備份與官方操作方式。

一件樂器可以很不規則，作品仍然需要方向。科技若能把控制權放在對的位置，就有機會讓意外更容易成為音樂。
